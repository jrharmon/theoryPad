Three coats of paint for the same app

Each mockup below is the same markup — the real home and practice screens rebuilt element for element — with only the stylesheet swapped. No control moves, no copy changes, no key changes. Pick a direction, and its spec is written so another agent can apply it without redesigning anything.

Light and dark: the app is light only today. Fiesta and Notebook each have a dark variant (switch with D) that would follow the Mac’s appearance setting on its own; Tolex is dark only.

Decided 2026-09-13: Notebook, light and dark, with an Appearance setting (System / Light / Dark, default System) in Settings → Display. Implementation doc: docs/plan/11-RESTYLE.md.

Found while looking: the app names Archivo in its font stack but never loads it, so it only renders where Archivo happens to be installed; everyone else on the live site gets the system font. Every direction here self-hosts its faces with Fontsource, which also keeps the app working offline.
